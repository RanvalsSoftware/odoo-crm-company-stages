Good to know

Clear boundaries.
No surprises.

A small tool with a specific job: company-aware CRM pipeline stages.

Can one salesperson work in both companies?

Yes. The stage belongs to a company independently of the salesperson. Existing opportunity access rules still apply; this addon does not grant new permissions.

Why can I still see stages from both companies?

Check the company selector. With Company A and Company B selected together, both sets are intentionally visible. Shared stages remain visible, subject to sales-team restrictions.

Will my existing stages or opportunities move?

No automatic reassignment is performed. Existing stages remain shared on a fresh installation. Assign them deliberately; conflicting active or archived opportunity links are blocked rather than silently moved.

Does this separate CRM tags?

No. It separates pipeline stage columns, not the colored CRM tags attached to opportunities.

Does it work on Odoo Online?

Not on standard Odoo Online. It is a Python addon for Odoo.sh or self-hosted deployments. It depends only on the Community CRM addon; Enterprise-specific combinations still need staging validation.

Are there paid dependencies or tracking services?

No. The addon adds no paid dependency, remote license check, telemetry or API service. The static website uses no analytics, external fonts, cookies or account system.

What testing and support are included?

Each package includes 38 Odoo integration test methods plus a Turkish QA report. The publication workflow runs these tests in disposable Odoo/PostgreSQL databases; inspect the repository Actions for results. Community support has no promised response time; there is no paid support contract included.
