# Tanıtım sitesi
`index.html` dosyasını tarayıcıda açın. Kurulum/derleme gerekmez.
Şirket A / B / Both düğmeleri temsili işleyişi gösterir; gerçek Odoo bağlantısı yoktur.
`downloads/` içindeki üç ZIP için indirme bağlantıları hazırdır.
Sayfa İngilizcedir; her modülün içinde Türkçe kurulum ve QA belgeleri vardır.
Çerez, analitik, uzak font, harici JavaScript veya API çağrısı yoktur.
GitHub Pages için paket içindeki PUBLISH_TR.md belgesini izleyin.
Canlı mağaza ilanı ve Odoo runtime testleri tamamlandığında sarı yayın durumu notunu
kanıtlanan sonuçlarla güncelleyin. Temsili çizimleri gerçek Odoo ekran görüntüsü diye sunmayın.
