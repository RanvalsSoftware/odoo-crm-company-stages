# CRM Company Stages — başlangıç

Üç Odoo sürümü, İngilizce Apps açıklaması ve tanıtım sitesi bu pakette.

- Tek bir Odoo'ya kurulum: sürümünüze ait bağımsız ZIP'i kullanın.
- Web sitesini görme: `website/index.html` dosyasını açın.
- Yayın adımları: `PUBLISH_TR.md`.
- Test edilen / edilmeyen işlemler: `QA_OVERVIEW_TR.md`.
- GitHub'a hazırlık: `crm-company-stages.git.bundle` ve `publish_github.py`.

**Henüz Odoo Apps üzerinde yayınlanmadı.** Gerçek Odoo/PostgreSQL kurulum testleri
çalıştırılmadı. Eski kurulu modülü kaldırmayın; yeni teknik isim ayrıca migrasyon ister.
Yayın dosyalarında ödeme/anahtar/müşteri bilgisi yoktur.
